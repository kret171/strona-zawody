# Bike Trip One-Pager


Run locally:

```bash
npm install
npm run dev
```

This is a minimal Vite + React + Tailwind setup for the brutalist one-page layout and price calculator.

Images and GPX:

- Copy the provided hero/logo image to `public/images/megaevent-hero.jpg` (hero banner)
- Copy the provided logo to `public/images/megaevent-logo.jpg` (top header)
- Copy bike images with these filenames into `public/images/`:
	- `bike-aspect.jpg`
	- `bike-patron.jpg`
	- `bike-strike.jpg`
	- `bike-subsport.jpg`
	- `bike-subsport-men.jpg`
- Place your GPX file as `public/trasa.gpx` (the app loads `/trasa.gpx` for the map)

After copying images and GPX, restart dev server if running.
